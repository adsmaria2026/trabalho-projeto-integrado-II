Introdução à Modelagem de Dados

A modelagem de dados é utilizada para representar como as informações de um sistema serão organizadas e relacionadas.

Principais conceitos

• Entidade: representa algo que possui informações no sistema;

• Atributo: característica de uma entidade;

• Relacionamento: representa a ligação entre entidades.

Modelo Entidade-Relacionamento

O modelo entidade-relacionamento representa visualmente as entidades, seus atributos e os relacionamentos existentes entre elas.
